# Marketing playbook

Everything in this folder is a **draft for Peter to post from his own accounts** —
nothing here is auto-published. Authenticity is the strategy: developer-tool
audiences reward "I built this, tell me what's wrong with it" and punish anything
that smells automated.

## Launch sequence (do in this order)

1. **Week 1 — Product Hunt** (`launch/product-hunt.md`). Needs screenshots exported first.
2. **Week 1, two days later — Show HN** (`launch/show-hn.md`). Biggest traffic risk/reward.
   Check droplet capacity that morning.
3. **Week 2 — Reddit** (`launch/reddit.md`), one subreddit per week, adapted per rules.
4. **Ongoing — SEO content** (`seo-content-plan.md`), one Tier 2 guide per week.
5. **Directory sweep** (one evening): AlternativeTo, SaaSHub, ToolFinder, Uneed,
   dev-tool GitHub awesome-lists (submit via PR), IndieHackers product page.

## Rules

- Never post identical text in two places.
- Every claim in every draft is true today (10 free scans/day, 8 languages, ~30s scans,
  $29/mo Pro, $20 day pass). If pricing changes, update drafts before posting.
- No fake urgency, testimonials, or user counts anywhere, ever.
- The weekly marketing routine (scheduled agent) produces a digest of drafts and
  relevant conversations — everything it produces is also post-it-yourself.
